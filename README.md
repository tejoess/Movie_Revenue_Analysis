# 🎬 Movie Revenue Analysis 📊🚀

A data analysis project exploring 4,700+ movies to uncover patterns in budget, revenue, popularity, ratings, and more!  
This is a beginner-friendly yet powerful project to strengthen my Python data analysis skills.

---

## 🚀 Project Highlights

- Loaded & cleaned movie dataset
- Handled missing values and dropped irrelevant columns
- Filtered & transformed key attributes for better insights
- Visualized trends using **Pandas**, **Matplotlib**, and **Seaborn**

---

## 📌 Key Insights

- 💸 High budget doesn’t guarantee high revenue
- 🚀 Sci-Fi, Marvel & Animated movies perform the best
- 📊 Budget & revenue are weakly correlated
- ⭐ Low-rated & mid-rated movies sometimes earn more
- 🎯 High-budget movies don’t always get better reviews
- ⏳ 100-200 min movies perform better on average
- 🌎 English-language movies dominate the dataset
- 💰 Big-budget films are rare but impact industry revenue
